# Как я устал от обрывов корпоративного VPN и написал watchdog на Go с потреблением 8 МБ RAM

Каждый, кто работает на удаленке с корпоративным VPN, знаком с этой болью: отходишь за кофе или переключаешься между вкладками — и видишь, что SSH-сессия повисла, внутренний Git недоступен, а корпоративный портал выдает ошибку сети.

VPN-туннель снова тихо упал.

Первая мысль любого инженера — автоматизировать. Но когда я попробовал стандартные решения и самописные скрипты, то столкнулся с неожиданной проблемой: **они начинают сражаться с пользователем**.

В этой статье я расскажу, как спроектировал и собрал **VPN Guardian** — ультралегковесную утилиту для Windows в системном трее на Go, которая стабильно держит туннель, не ест ресурсы и корректно понимает, когда я сам хочу выключить VPN.

---

## В чем проблема наивного автореконнекта?

Самый простой скрипт на PowerShell или Bash выглядит так:
```powershell
while ($true) {
    if (-not (Test-Connection 10.0.0.1 -Quiet)) {
        rasdial "CorpVPN"
    }
    Start-Sleep 5
}
```

Работать-то он работает. Но ровно до вечера, когда рабочий день заканчивается:
1. Вы нажимаете «Отключить VPN».
2. Скрипт через 3 секунды видит, что связи нет, и бодро включает его обратно.
3. Вы снова отключаете. Он снова включает.
4. Приходится открывать Диспетчер задач и принудительно убивать процесс.

Ставить ради этого монструозные решения на Electron или Python тоже не хотелось: отдавать 100–150 МБ оперативной памяти под фоновую иконку возле часов — преступление против оптимизации.

---

## Архитектура решения: State Machine в системном трее

Главный инсайт: **приложение обязано различать аварийный обрыв связи и осознанное действие человека**.

Для этого была спроектирована простая машина состояний:

```
               [ Пользователь нажал "Подключить" ]
                      │               ▲
                      ▼               │
             ┌─────────────────┐      │
             │   MONITORING    │      │
             │  (Авторежим)    │      │
             └────────┬────────┘      │
                      │               │
  [VPN упал сам]      │ [Пользователь нажал "Отключить"]
        │             │               │
        ▼             ▼               │
 ┌─────────────┐   ┌──────────────────┴──┐
 │ Reconnect   │   │       PAUSED        │
 │ (Серия из   │   │  (Ручное отключение:│
 │ 10 попыток) │   │  VPN выключен,      │
 └─────────────┘   │  автореконнект спит)│
                   └─────────────────────┘
```

1. **State: Active Monitoring (🟢)**
   Фоновый поток раз в 5 секунд проверяет статус. Если происходит обрыв — утилита делает контролируемую серию из 10 попыток переподключения с интервалом в 4 секунды и выводит уведомление в Windows.
2. **State: Manual Paused (⚪)**
   В системном трее есть кнопка **«⏹ Отключить VPN (ручная пауза)»**. При нажатии приложение **само** разрывает соединение и переходит в статус `PAUSED`. Никаких попыток восстановить связь не предпринимается.
3. **State: Temporary Pause (⏸)**
   Возможность заглушить автореконнект на 30 минут или 1 час (например, чтобы зайти в личный банк без корпоративного прокси).

## Почему именно Go?

1. **Минимальный футпринт:** бинарник занимает ~2.5 МБ, потребляет всего **8–12 МБ RAM**.
2. **0.0% CPU в простое:** нативный цикл обработки сообщений Windows (`GetMessageW` / `DispatchMessageW`) переводит поток в режим ожидания на уровне ядра Windows.
3. **Zero CGO:** приложение работает напрямую с Win32 API (`shell32.dll`, `user32.dll`), собираясь стандартным компилятором Go без MinGW / GCC.

### Хак с мгновенным определением профилей VPN
Вместо вызова тяжелого `powershell Get-VpnConnection`, который стартует за 1.5–2 секунды, приложение парсит телефонную книгу Windows `rasphone.pbk` напрямую:

```go
func extractFirstPbkSection(path string) string {
    data, err := os.ReadFile(path)
    if err != nil {
        return ""
    }
    // Парсим секции [CorpVPN] за доли микросекунды
    for _, line := range strings.Split(string(data), "\n") {
        line = strings.TrimSpace(line)
        if strings.HasPrefix(line, "[") && strings.HasSuffix(line, "]") {
            return strings.Trim(line, "[]")
        }
    }
    return ""
}
```
Это позволило сократить время инициализации до **0.05 секунды**.

## Поддержка протоколов

Утилита спроектирована модульно (через интерфейс `VPNAdapter`) и из коробки поддерживает:
* **Windows Built-in VPN (`rasdial`):** SSTP, L2TP, IKEv2, PPTP (встроенный в Windows).
* **WireGuard:** управление службами туннелей `/installtunnelservice` и `/uninstalltunnelservice`.
* **OpenVPN:** взаимодействие с CLI `openvpn-gui.exe`.

Настройки сохраняются в `%APPDATA%\VPNGuardian\config.json` и редактируются в 1 клик прямо из меню трея.

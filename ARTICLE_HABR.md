# Автореконнект корпоративного VPN без прав администратора: пишем watchdog на Go с потреблением 8 МБ RAM

Каждый, кто работает на корпоративном ноутбуке, знает эти два ограничения:
1. **У вас нет прав локального администратора** — корпоративная служба безопасности заблокировала UAC, установку стороннего софта, драйверов и системных служб.
2. **Корпоративный VPN постоянно отваливается** — мигнул Wi-Fi, сменился IP провайдера или просто истек таймаут SSTP-сессии.

В итоге: SSH-сессия повисла, `git push` падает по таймауту, внутренний трекер задач и базы данных недоступны. Приходится постоянно отвлекаться от работы, открывать сетевые настройки и вручную тыкать кнопку «Подключить». За день такое может происходить десятки раз, напрочь ломая фокус и рабочий поток.

«Ванильные» решения из интернета здесь бессильны: они либо требуют прав администратора для установки своих виртуальных адаптеров и демонов, либо представляют собой 150-мегабайтные Electron-монстры.

В этой статье я расскажу, как спроектировал и собрал **TunnelKeep** — ультралегковесную утилиту для Windows в системном трее на Go, которая работает **полностью без прав администратора**, автоматически удерживает туннель в фоне и потребляет всего 8–12 МБ оперативной памяти.

---

## Архитектура: как обойтись без прав администратора?

Главная задача — управлять сетевым туннелем строго в пользовательском пространстве (**User Space**).

В Windows встроен богатый, но часто недооцененный инструментарий Remote Access Service (RAS):
1. **Пользовательская телефонная книга (`rasphone.pbk`):**
   Корпоративные VPN-подключения (SSTP, L2TP, IKEv2), настроенные на машине, сохраняются прямо в профиле пользователя:
   `%APPDATA%\Microsoft\Network\Connections\Pbk\rasphone.pbk`.
   Для чтения этого файла **права администратора не нужны вообще**.
2. **Штатный `rasdial.exe`:**
   Встроенная системная утилита умеет инициировать и разрывать сохраненные пользовательские RAS-соединения без повышенных привилегий.
3. **Win32 Shell Notify Icon API:**
   Взаимодействие с системным треем (`Shell_NotifyIconW`) также целиком работает в пользовательской сессии.

### Мгновенный старт без тяжелых вызовов
Вместо вызова командлета PowerShell `Get-VpnConnection`, инициализация которого занимает 1.5–2 секунды, приложение парсит `rasphone.pbk` напрямую на Go за доли миллисекунды:

```go
func extractFirstPbkSection(path string) string {
    data, err := os.ReadFile(path)
    if err != nil {
        return ""
    }
    for _, line := range strings.Split(string(data), "\n") {
        line = strings.TrimSpace(line)
        if strings.HasPrefix(line, "[") && strings.HasSuffix(line, "]") {
            return strings.Trim(line, "[]")
        }
    }
    return ""
}
```

## Логика работы: автоматический фоновый контроль

Утилита висит в трее и освобождает голову разработчика:
* **Фоновый мониторинг (🟢):** раз в 5 секунд опрашивает статус туннеля через быстрый неблокирующий вызов.
* **Автоматическое восстановление:** если связь оборвалась, приложение делает серию контролируемых попыток переподключения с интервалом в 4 секунды и выводит уведомление в Windows.
* **Автозагрузка без админских прав:** ярлык кладется в пользовательскую папку автозагрузки `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`.

### Мелкая деталь, которую мы сразу учли: «умная пауза»
В самописных скриптах часто встречается раздражающая проблема: когда в конце дня вы сами выключаете VPN, скрипт видит разрыв и тут же назойливо включает его обратно. 

В TunnelKeep реализована простая машина состояний (State Machine):
* Кнопка **«⏹ Отключить VPN (ручная пауза)»** в трее: приложение само разрывает туннель и **замораживает мониторинг**. Оно не будет переподключать VPN заново, пока вы явно не нажмете *«⚡ Подключить»*.
* **Временная пауза:** возможность приглушить автореконнект на 30 минут или 1 час (например, чтобы зайти в личные сервисы без корпоративного прокси).

## Почему именно Go?

* **Потребление памяти:** всего **8–12 МБ RAM** (в простое поток спит в системном вызове `GetMessageW`).
* **Нагрузка на процессор:** **0.0% CPU**.
* **Zero CGO:** чистый Go без зависимостей от GCC/MinGW, прямые системные вызовы Win32 API.
* **Отказоустойчивость:** подписка на системное событие `TaskbarCreated` гарантирует, что иконка в трее не пропадет при перезапуске `explorer.exe`.

Настройки хранятся в `%APPDATA%\TunnelKeep\config.json` и открываются в 1 клик прямо из трея. Помимо штатного Windows VPN, архитектура также поддерживает WireGuard и OpenVPN, а также автоопределение системного языка (русский / английский).
